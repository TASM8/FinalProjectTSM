## Description
This project is a GUI-based version of the classic 20 Questions game.

The program uses a smart trait-based elimination engine instead of a simple decision tree. The game asks the player up to 20 questions in order to guess the object, place, animal, person, or character the player is thinking of.

The game includes:
- Multiple categories
- Intelligent question selection
- Dark mode GUI
- Optional sound effects
- Large answer database
- Input validation
- Question tracking system
