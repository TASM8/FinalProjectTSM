Final Reflection
Project Overview

For my final project, I created a GUI-based version of the classic 20 Questions game in Python. The program attempts to guess what the player is thinking of by asking up to 20 yes-or-no questions. The final version includes multiple categories, a dark mode graphical interface, sound effects, and a large built-in answer database.

The project originally started as a very small text-based program that only guessed a few animals. Over time, I expanded the project into a much larger and more advanced program with improved organization, additional categories, and smarter guessing logic.

Challenges Faced

One of the biggest challenges I ran into was getting the guessing system to work correctly. Earlier versions of the program would sometimes stop after only a few questions or make incorrect guesses too early. I had to repeatedly test and modify the elimination system so the game could continue asking questions properly and narrow down answers more accurately.

Another major challenge for me was working with loops and program flow. Loops have always been difficult for me, and I struggled with getting the game to continue correctly without stopping unexpectedly. Through testing and debugging, I learned more about how loops, conditions, and question tracking work together.

I also had challenges organizing the code. As the project became larger, the code became difficult to read and manage. I improved this by separating sections more clearly, adding comments, and organizing functions and classes more effectively.

Another mistake I made during development was not linking the project to GitHub correctly at first. This taught me the importance of carefully reading project instructions and properly managing project files.

What I Learned

This project helped me better understand:

GUI programming using tkinter
Functions and classes
Loops and conditionals
Dictionaries and large databases
Organizing larger Python projects
Debugging and testing code
Using Python libraries such as pygame, threading, and numpy

I also learned how important testing is during development because many problems only appeared after running the program multiple times.

AI Assistance

AI tools were used to help debug problems, organize the code, improve readability, and troubleshoot issues with the GUI, colors, loops, and sound effects. AI assistance helped me better understand where errors were happening and how to improve the overall structure of the project.

Even with AI assistance, I still had to repeatedly test, modify, and correct the program myself throughout development.

Final Thoughts

Overall, I am proud of how much the project improved from the original starter version. The final program became much larger and more advanced than my original idea, and it helped me strengthen my Python programming skills and better understand how larger programs are structured.
